# М3. Конденсатор

## [Общая информация](/labs/the_capacitor)

## Тесты

Емкость центральной части дискового конденсатора
1. Проверить симметричность распределения зарядов на обкладках (сумма должна быть близка к нулю)
2. Сравнить измеренную емкость с теоретическим значением

### Особенности моделирования
При моделировании конденсатора нужно соблюдать несколько соотношений:
1. Радиус конденсатора должен быть существенно больше расстояния между пластинами.
2. Расстояние между пластинами должно быть намного больше, чем радиус точечного заряда, чтобы избежать влияния дискретизации (иначе, пластины превращаются в наборы диполей (из верхней и нижней пластин), которые взаимодействуют только попарно между собой).
3. При этом, чтобы тесты считались за разумное время, мы придерживаемся радиуса около 40 точек.

## Теория

В качестве модели мы используем плоский конденсатор в форме круга, состоящий из двух заряженных пластин (с напряжениями $V/2$ и $-V/2$, чтобы заряд не "утекал в бесконечность")

### Емкость конденсатора

Для расчетов используется система единиц СГС, поэтому электрическая постоянная $\varepsilon_0 = \frac{1}{4\pi}$.
Теоретическая емкость плоского конденсатора вычисляется по формуле:

$$
C = \frac{\varepsilon_0 S}{d} = \frac{S}{4\pi d}
$$

В тестах проверяется, что для центральной области вдали от краев (где краевые эффекты минимальны) емкость совпадает с теоретической для заданного расстояния $d$ и площади выделенного центрального участка $S$. Она считается как сумма всех зарядов на одной пластине, деленную на разность потенциалов.
