# М7. Идеальный газ

## Задача

Смоделировать поведение идеального газа в замкнутом контейнере.
Необходимо проверить выполнение распределений Максвелла (по скоростям) и Больцмана (по высоте), а также рассчитать макроскопические параметры системы: температуру и давление.

## Входные параметры

### Параметры газа

- **Количество молекул**: 500 - 5000, по умолчанию 1000
  - Определяет статистическую точность моделирования. Чем больше молекул, тем точнее результаты, но выше вычислительная нагрузка.

- **Концентрация (на м³)**: настраиваемая, по умолчанию $1 \times 10^{25}$
  - Определяет плотность газа и, соответственно, объем контейнера при фиксированном числе молекул.

- **Молярная масса (г/моль)**: 1 - 50, по умолчанию 4 (гелий)
  - Масса одного моля вещества. Влияет на инерцию молекул и их скорости при заданной температуре.

- **Радиус молекулы (нм)**: 0.1 - 10.0, по умолчанию 0.14 (гелий)
  - Размер молекул, учитывается при расчете столкновений.

- **Диапазон начальных скоростей (м/с)**: промежуток в границах 100 - 2000, по умолчанию 600 - 900 (взято как пример для гелия при комнатной температуре)
  - Задает начальное распределение скоростей молекул. В процессе эволюции системы распределение стремится к максвелловскому.

### Параметры среды и симуляции

- **Соотношение сторон контейнера**: 0.1 - 10.0, по умолчанию 1.0 (куб)
  - Отношение высоты контейнера к длине стороны основания. Позволяет исследовать "высокие" или "плоские" сосуды. Важно для Больцмановского распределения по высоте.

- **Гравитация**: вкл/выкл, по умолчанию выкл
  - Влияет на распределение молекул по высоте (распределение Больцмана).

- **Внутренние соударения**: вкл/выкл, по умолчанию выкл
  - Учет столкновений молекул друг с другом. При выключенном параметре молекулы взаимодействуют только со стенками.

- **Количество шагов симуляции**: 10 - 1000, по умолчанию 100
  - Длительность эксперимента.
