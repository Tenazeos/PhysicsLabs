# М3. Основная задача электростатики

## Задача

Смоделировать магнитную ловушку, состоящую из двух колец с током, расположенных друг над другом. Проверить, что расчеты полей близки к теоретическим оценкам индукции магнитного поля

## Модель

- Расчеты производятся в системе единиц СГСМ.
- Каждое кольцо разбивается на небольшие участки, которые считаем за участки прямых проводников, каждый из них порождает магнитное поле, которые векторно суммируются
- Решаем дифференциальное уравнение для вычисления положения и скорости частицы под влиянием силы
