# М1. Основная задача электростатики


## Задача

Смоделировать конденсатор с обкладками различной формы (диск, прямоугольник).  
Построить картину силовых линий поля в пространстве между обкладками, найти емкость системы.


## Модель

- Расчеты производятся в системе единиц СГСЭ.
- Каждая пластина разбивается на небольшие участки — **чанки**, которые рассматриваются как точечные заряды.
- Для нахождения распределения зарядов решается система линейных уравнений, исходя из условия, что потенциал на проводящей пластине постоянен:
  - на верхней пластине потенциал равен $V/2$
  - на нижней пластине потенциал равен $-V/2$


## Входные параметры

### Общие параметры

|          Параметр           | Размерность |   Ограничения   |                                        Обоснование                                         |
|:---------------------------:|:-----------:|:---------------:|:------------------------------------------------------------------------------------------:|
|         Напряжение          |     $В$     |     0 — 100     | Важны не ограничения, а факт, что этот параметр не влияет на все рассчитываемые параметры  |
| Расстояние между пластинами |    $мм$     | 5 — `min\_side` | Ограничено для корректности модели плоского конденсатора (избежания влияния дискретизации) |

### Геометрия пластин

- **Для прямоугольника**: Длина и ширина каждой пластины (1 — 4 см)
- **Для диска**: Радиус каждой пластины (1 — 4 см)

Размеры ограничены сверху для сохранения разумного времени вычислений.


## Визуализация

- **3D Поле**: Интерактивное отображение векторов напряженности $\vec{E}$ в объеме.
  Интенсивность поля кодируется цветом и размером стрелок (с использованием степенного масштабирования для наглядности).
- **Срез поля**: 2D визуализация векторов и интенсивности в горизонтальной плоскости на произвольной высоте (регулируется слайдером).
- **Распределение заряда**: Тепловые карты, показывающие распределение электрического заряда внутри обкладок конденсатора.
